# SupportPilot Starter

A clean, responsive, HTML/CSS-only ticket dashboard starter for practicing JavaScript.

## Files

- `index.html` — semantic dashboard markup and stable IDs for JavaScript practice
- `css/styles.css` — all visual styling and responsive layout
- `js/app.js` — intentionally contains no implementation; write your own JavaScript here

## Run

Open `index.html` in your browser. A local development server (such as VS Code Live Server) is recommended.

## Important

- The table starts with an empty state intentionally.
- Summary values are placeholders intentionally.
- Search and filter controls are markup only until you implement their behavior in JavaScript.
- Do not treat the fictional UI as a real support system or use real customer data.
